Meine Ausbildung bei CodersBay

Vom Beruf als CRM Manager zur eigenen Website: Hier zeige ich, was ich in den ersten Wochen meiner Ausbildung bei CodersBay Vienna gelernt habe. Ich gehe Schritt für Schritt vor, so wie die Aufgaben im Kurs aufeinander aufbauen.

Ausgangspunkt

In meinem Beruf arbeite ich viel mit CRM-Systemen, Prozessautomatisierung und SQL. Ich wollte verstehen, wie das Web hinter diesen Tools funktioniert. Deshalb habe ich die Ausbildung zum Webdeveloper bei CodersBay begonnen.

Meine Ziele für die Ausbildung:

  • Websites selbst mit HTML und CSS bauen
  • Sauberen und barrierefreien Code schreiben
  • Mein technisches Wissen mit meiner CRM-Erfahrung verbinden

Mein Weg in acht Schritten

  1. 1

    Hallo Welt

    Meine erste Datei: hallowelt.html mit der HTML-Grundstruktur, dem Titel „Hallo Welt“ und meinem Namen im Body.

  2. 2

    Erste kleine Website

    Überschriften, Absätze, Textformatierungen und Links. Danach kamen Bilder, Tabellen und Listen dazu.

  3. 3

    Seite nachbauen

    Eine Seite zum Thema „Warum sind Katzenvideos so beliebt?“ nur anhand eines Screenshots nachgebaut. Dabei habe ich gelernt, Strukturen zu erkennen.

  4. 4

    Formulare

    Textfelder, Textareas, Checkboxen, Radio Buttons, Select-Box und Submit-Button, mit Attributen wie placeholder und required.

  5. 5

    Gestaltung mit CSS

    Selektoren, Farben, Rahmen, Text und Schriften. Zuerst als Inline CSS und Internal CSS.

  6. 6

    Mehrere Seiten

    Weitere Seiten in einem Unterverzeichnis, verbunden über relative Links. Das CSS liegt jetzt in einer eigenen Datei.

  7. 7

    Semantisches Layout

    Aufbau mit header, main und footer, ohne störende Scrollbalken.

  8. 8

    Navigation mit Flexbox

    Ein Header mit Navigation. Der wichtigste Trick: Flexboxen lassen sich verschachteln.

Übersicht

Gelernte Themen und Elemente pro Aufgabe
Aufgabe Thema Wichtigste Elemente
1 Hallo Welt html, head, title, body
2 Erste Website h1–h6, p, strong, em, a, img, table, ul, ol
3 Seite nachbauen mark, hr, table, ol, img
4 Formulare form, input, label, select, textarea, button
5 CSS Selektoren, Farben, Rahmen, Text, Schriften
6 Mehrere Seiten Relative Links, External CSS
7 Layout header, main, footer
8 Navigation nav, Flexbox

Fazit

Gute Websites entstehen Schicht für Schicht:

  1. Zuerst die Struktur mit HTML
  2. Dann das Design mit CSS
  3. Zum Schluss das Layout mit Flexbox
